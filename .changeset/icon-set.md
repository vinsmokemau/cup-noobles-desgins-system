Choose the icon set (TBD-19, OD-09, ADR-0012). The icon set is Phosphor Bold. The Nuxt layer depends on `@iconify-json/ph` and sets every icon name that Nuxt UI components use (`ui.icons`) to its Phosphor Bold glyph, so a button's loading spinner, a close button, and the chevrons all come from one set.
