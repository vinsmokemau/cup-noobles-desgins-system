# Cup Noobles — Design Context

Reference document for the visual identity and design rules of the **Cup Noobles** brand (gaming / anime / geek content platform). Use this as context for design, UI, and content generation tasks.

## Color Palette

| Role | Hex | Notes |
|------|---------|-------|
| Primary | `#ef80ae` | Neon/hot pink. The protagonist color — should dominate the visual identity. |
| Secondary | `#fff488` | Bright yellow/gold. Used as a luminous, premium accent color. |
| Tertiary | `#000000` | Pure black. Base/background color — must stay pure black, not dark gray. Provides contrast and depth. |

## Brand Aesthetic

- Geek / gaming / anime / TCG / board game culture
- Retro-arcade, neon, "sticker mascot logo" style
- Premium, fun, and energetic — never childish or generic
- High-contrast, vibrant, legible
- Should feel like a well-built geek brand, ready for stream/content platforms (Twitch, YouTube, etc.)

## Typography

- Bold, retro display sans-serif (similar in feel to the brand logo)
- Clear size hierarchy: H1 → H2/H3 → body → caption
- Should feel bold, geek, premium, with strong presence and easy legibility (including on stream overlays)

## Components & UI Rules

**Buttons**
- Rounded corners
- Subtle neon glow effect
- Thick outline stroke
- States: primary, secondary, ghost, disabled

**Cards**
- Dark surface with neon highlights
- Standard content card
- Featured media card (e.g., anime thumbnail + title + tag badge)

**Line work**
- Thick, clean, high-contrast outlines throughout all UI and illustration elements

## Decorative Motifs / Brand Imagery

- Sparkle / star details
- Sticker-style borders
- Pink ramen cup (core brand icon) with gamer details
- Noodles / noodle-inspired curves and waves
- Golden d20 die
- Chopsticks
- Arcade/gamer-inspired shapes and dynamic lines

## Usage Context

- Design system should be **responsive** — built to work across both mobile and web/dashboard
- Also used for stream overlays / stream screens (e.g., "Starting Soon" screens)
- Brand assets include: a circular "CN" icon, a vertical "Cup Noobles" logo lockup, and a horizontal "Cup Noobles" wordmark/logo

## Overall Feel to Convey

Anticipation, hype, energy, gamer/geek identity, visual professionalism, and memorable branding — the sense that Cup Noobles is about to deliver gaming, board game, TCG, and geek culture content.
