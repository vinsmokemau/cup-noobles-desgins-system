# ADR-0061: Release 1.0.0

## Context

ADR-0045 kept the packages on 0.x until every TBD item was closed, and said the owner confirms the release in chat and a new ADR records it. The register is closed (0 open items). ADR-0060 settled the draft component docs, so no doc under `docs/` is `draft` or `tbd`, and ADR-0006 is the only doc that is not `stable`. `pnpm release:check` passes. The last pushed commits ran green in CI, Deploy showcase, and Release on 2026-10-19.

## Decision

The owner decided to release 1.0.0, in chat on 2026-10-19: "Runs are green. A", answering the question "Do you decide to release 1.0.0 of the three packages now?" with A (yes).

The three packages (`@vinsmokemau/cup-noobles-tokens`, `@vinsmokemau/cup-noobles-nuxt`, and `@vinsmokemau/cup-noobles-email`) are released together at `1.0.0`. A major changeset covers all three. The release goes through the usual flow: the "Version packages" pull request is merged on GitHub, the packages are published privately to GitHub Packages (OD-03), and the showcase is deployed (OD-02).

## Consequences

- From `1.0.0`, a breaking change is a major release, an addition is a minor release, and a fix is a patch release (REQ-070).
- Claude Code does not push, merge, or publish on its own. The owner confirms each step in chat: the push, and the merge of the "Version packages" pull request.
- `versioning-and-releases.md` and SPEC.md A-04 say the release has happened.
- This ADR replaces the waiting rule in ADR-0045. The 0.x line ends.
